# 연금의 심연 (Alchemic Abyss)

픽셀 단위 물리 시뮬레이션 기반 2D 사이드뷰 액션 로그라이트. 화면의 모든 픽셀이 재질을 가진 입자이며
불은 번지고, 물은 흐르고, 산은 녹이고, 화약은 연쇄 폭발한다. 마법 지팡이로 세계를 파괴하며 5개 구역을 지나
최종 보스 「연금 심장」까지 내려가는 게임이다.

외부 런타임 라이브러리, 이미지, 사운드 파일 없이 TypeScript + Canvas 2D + WebAudio만으로 만들었다.

## 실행 방법

```bash
npm install
npm run dev        # 개발 서버 (브라우저에서 표시된 주소 열기)
npm run build      # 타입 체크 + 프로덕션 빌드 (dist/)
npm test           # Vitest: 시뮬레이션 반응 단위 테스트
npm run e2e        # Playwright 헤드리스 스모크 테스트 (스크린샷: screenshots/)
```

## 조작법

| 키 | 동작 |
|---|---|
| A / D | 좌우 이동 |
| W / Space | 점프. 공중에서 누르고 있으면 부양 (부양 게이지 소모, 착지 시 회복) |
| 마우스 | 조준, 좌클릭 시전 (누르고 있으면 연사) |
| 1 ~ 4 / 마우스 휠 | 지팡이 교체 |
| E | 상호작용 (보물 상자, 아이템, 상점, 치유 제단, 무료 주문, 포털) |
| Tab | 인벤토리 (카드 드래그 앤 드롭, 툴팁) |
| Esc | 일시정지 |
| M | 음소거 |
| F3 | 디버그 오버레이 (FPS, 활성 청크 수, 입자 수, 청크 경계) |

**터치 기기:** 왼쪽 조이스틱으로 이동(위로 밀면 점프). 오른쪽 조준 조이스틱은 누른 채 방향을 정하면 조준선이 보이고, 떼면 그 방향으로 한 번 발사합니다(가운데로 되돌려 떼면 취소). 오른쪽 아래 버튼으로 점프·부양과 상호작용(E). 빈 화면을 누르고 있으면 그쪽으로 연사합니다. 아래 지팡이 칸을 탭하면 지팡이를 바꾸고, 미니맵 아래 버튼으로 가방과 일시정지를 엽니다. 메뉴와 인벤토리는 탭과 드래그로 조작합니다. 화면 크기에 맞춰 캔버스가 확대됩니다.

샌드박스: 좌클릭 그리기, 우클릭 지우기, 휠/[ ] 브러시 크기, Space 일시정지, N 한 프레임 진행, C 전체 지우기, Esc 나가기, 상단 버튼으로 속도(×0.25~×4) 조절.

## 게임 흐름

1. 제1구역 뿌리 동굴 → 성소 1 → 제2구역 얼음 동굴 → 성소 2 → 제3구역 독의 늪 → 성소 3 → 제4구역 화약 광산 → 성소 4 → 제5구역 용암 심층 → 성소 5 → 최종 「연금 심장」
2. 각 구역은 노이즈 동굴, 보장된 하강 경로, 미리 설계한 방 조각(다리 호수, 화약 창고, 대장간, 버섯 동굴, 얼음 호수, 결정 사당, 비밀 금고)을 섞어 절차 생성한다. 바닥의 포털(E)로 다음 단계로 간다.
3. 성소에서는 체력과 마나가 회복되고, 치유 제단, 카드/지팡이 상점(구역에서 모은 금 사용), 무료 주문 3장 중 1장 선택이 가능하다.
4. 금은 적 처치, 보물 상자, 벽 속 금맥(굴착하면 금가루가 흘러내림), 녹은 금(식으면 금가루)에서 얻는다. 금가루에 닿으면 자동으로 줍는다.
5. 비밀 금고는 벽 속에 완전히 묻혀 있다. 굴착 광선이나 폭탄으로 벽을 부숴야 찾을 수 있다.

### 최종 보스 「연금 심장」
- 1페이즈 범람: 천장 배수구에서 물이 차오른다. 물에 젖은 심장은 전기에 약하다. 얼음 창이나 냉기 구체로 물을 얼려 발판을 만든 뒤 번개 볼트를 물에 쏘면 연결된 물 전체가 감전된다.
- 2페이즈 용암의 비: 붉은 표식이 예고한 지점에 용암이 쏟아진다. 남은 물과 만나 돌과 증기가 된다. 이 페이즈의 심장은 냉기에 약하다.
- 3페이즈 산의 붕괴: 초록 표식 아래로 산이 쏟아져 바닥과 발판을 녹이고, 지지대를 잃은 지형이 무너진다.
- 모든 공격(결정 파편 부채꼴, 파동, 소환, 환경 공격)에는 예고 연출이 있다. 보스 체력바, 이름, 페이즈 전환 연출(섬광, 흔들림, 히트스톱, 배너)이 표시된다.

  game/
    game.ts       런 관리: 레벨 로드, 업데이트 순서, 피해/폭발, 카메라, 상호작용, 연출
    player.ts     이동/점프/부양/수영, 시전, 상태이상 시각화
    entity.ts     픽셀 충돌 AABB(경사 2픽셀 오르기, 끼임 해소), 환경 접촉 피해, 상태이상
    spells.ts     카드 정의, 지팡이, 시전 파서(수정자/다중 시전/트리거)
    projectiles.ts 투사체 풀, 카드별 비행/명중 효과
    enemies.ts    적 7종 AI (순찰/감지/추적/도주), pathfind.ts 흐름장 길찾기
    boss.ts       연금 심장
    items.ts      상자/아이템/상점/제단/포털, worldgen.ts 절차 생성, noise.ts

  audio/audio.ts  WebAudio 절차 합성 (효과음, 불/물 지속음, 구역 드론, 보스 시퀀서)
  save.ts         localStorage 기록 (실패해도 동작)

### 데이터 레이아웃
셀 인덱스 `i = y*W + x`. 구조체 배열 대신 배열 구조체(SoA): `mat:Uint8`, `shade:Uint8`(색 변이), `temp:Int16`, `life:Uint16`(수명/낙하 속도/정착 카운터), `aux:Uint8`(연소 중인 원래 재질), `charge:Uint8`(전류), `stamp:Uint8`(프레임 중복 갱신 방지).

### 업데이트 순서 (프레임당)
입력 → 플레이어 → 흐름장(15프레임마다) → 적 → 보스 → 투사체 → 아이템 → 월드 스텝(활성 청크만, 아래→위, 좌우 순회 방향 교대; 셀마다 전류 → 반응 → 열 → 이동) → 폭발 큐(프레임당 최대 6개) → 자유 입자 → 강체 낙하 → 연결 영역 검사(8프레임마다, 이벤트 기반) → 낙하물 피해 → 사망 처리 → 카메라 → 렌더(배경 → 셀 → 엔티티 → 입자 → 발광 셀/광원 라이트맵 → 조명 곱 → 예고 오버레이 → 섬광) → UI → 오디오

### 성능
- 청크(64×64)마다 더티 렉트를 관리하여 변화 없는 영역은 건너뛴다. 카메라 주변 청크만 시뮬레이션하고, 먼 청크는 더티 상태를 보존한 채 잠든다.
- 끝없이 수평으로 떠도는 액체는 정착 카운터로 잠재운다.
- 투사체, 입자, 적 객체는 풀링해서 재사용한다. 화면에서 먼 적은 8프레임에 한 번만 갱신한다.

## 주문 카드

카드는 슬롯 순서대로 발사된다. 수정자는 다음 투사체(다중 시전 묶음이면 묶음 전체)에 적용된다. 트리거는 다음 투사체가 명중했을 때 그 다음 주문을 명중 지점에서 발동한다. 예를 들어 `트리거 → 물 분사 → 번개 볼트`는 적을 적신 뒤 감전시킨다(젖은 대상은 전기 피해 2배).

| 주문 | 종류 | 마나 | 설명 |
|---|---|---|---|
| 불꽃 볼트 | 투사체 | 5 | 빠르고 가벼운 마법 탄환. |
| 불덩이 | 투사체 | 25 | 명중 지점에 불길을 퍼뜨린다. 나무와 기름을 태운다. |
| 산 방울 | 투사체 | 20 | 포물선을 그리며 날아가 산 웅덩이를 만든다. 지형을 녹인다. |
| 얼음 창 | 투사체 | 22 | 적 하나를 관통하고 명중 지점을 얼린다. 물을 얼음 발판으로 만든다. |
| 번개 볼트 | 투사체 | 30 | 매우 빠른 전격. 물과 금속에 닿으면 연결된 전체로 전류가 흐른다. |
| 폭탄 | 투사체 | 35 | 튕기다가 잠시 후 폭발한다. 지형을 크게 파괴한다. |
| 물 분사 | 투사체 | 4 | 물줄기를 뿌린다. 불을 끄고 적을 적신다 (젖으면 전기에 약해짐). |
| 굴착 광선 | 투사체 | 7 | 지형만 파괴하는 광선. 적에게는 피해를 주지 않는다. |
| 모래 소환 | 투사체 | 15 | 모래 덩어리를 소환한다. 발판이나 방벽으로 쓸 수 있다. |
| 기름 소환 | 투사체 | 15 | 기름 덩어리를 소환한다. 불을 붙이면 크게 번진다. |
| 물 덩어리 소환 | 투사체 | 15 | 많은 물을 소환한다. 용암을 돌로 굳힌다. |

## 적

| 적 | 특징 | 약점 / 저항 |
|---|---|---|
| 산성 슬라임 | 뛰어다니며 산 흔적을 남김. 죽으면 산 웅덩이 | 불 1.5배 / 산 면역 |
| 불꽃 박쥐 | 날아다니며 닿는 곳에 불을 붙임, 치고 빠짐 | 냉기 2배, 물에 빠지면 피해 / 불 면역 |
| 굴착 벌레 | 지형을 파고 다니는 체절형 몸통 | 폭발 / 물리 저항 |
| 얼음 정령 | 주변을 얼리고 냉기 구체를 3발 발사 | 불 2.2배 / 냉기 면역 |
| 폭탄 운반자 | 접근하면 자폭(예고 깜빡임), 죽어도 폭발 | 폭발 저항 |
| 어둠 마법사 | 거리를 유지하며 예고 후 마법탄 시전, 체력이 낮으면 도주 | 마법 저항 |
| 석상 골렘 | 높은 체력, 예고 후 내려찍기 | 산 2.5배 / 물리, 불, 폭발 저항 |

모든 적은 불, 산, 감전, 독, 낙하물 같은 환경 피해를 플레이어와 똑같이 받는다. 흐름장(BFS) 길찾기로 지형을 돌아서 추적하며, 시야와 소리(시전, 폭발)로 플레이어를 감지한다.

## 기록
최고 도달 구역, 클리어 횟수, 최단 클리어 시간, 누적 처치 수, 최근 10회 기록을 `localStorage`에 저장한다. 저장에 실패하면(사생활 보호 모드 등) 무시하고 계속 진행한다.
